# C05 900-second matched experiment

This directory records the registered CP-SCALE-AU-L002 experiment begun on 9 October 2026. It is separate from the archived 360-second C05 results. The input is one physical contact source presented in eight constraint views, with seeds `67, 71, 73, 79, 83` for each view. The four registered arms are C05-Codex, C05-KNN, C05-LinUCB, and the original CHILS implementation under a custom matched configuration. The complete matrix has 160 positions, 40 per arm.

The complete 160-position matrix passed the independent identity, input-hash, objective and feasibility audit. The `main` branch publishes the 40 C05-Codex positions and their eight view means in [results](results/). The equal-view final mean is **1,138,760.36872255 contact-seconds**. Across those 40 positions, the detached `gpt-6-luna` controller made **840 model calls** and supplied **838 valid plan proposals**. The public [audit receipt](results/audit_public.json) records the private audit and model-I/O manifest hashes. Numeric results for the three other registered arms are on `non-llm-controls`.

Each position has a 900-second end-to-end solver budget, four search trajectories, and one native thread. The C05 controller first offers a plan decision at 20 seconds, then every 40 seconds; its cap is 21 selections. The C05 model arm requests `gpt-6-luna` through a detached [local relay](codex_transport/README.md). Its response is checked against the frozen C05 finite whole-plan registry and the observation snapshot. Native search continues while the model request is pending. KNN and LinUCB select from the same C05 plan registry. The CHILS arm uses the pinned original CHILS kernel with population four and `search_step=10`.

The graph SHA256 values, seeds, wall-time budget, population, source patch, and intended CPU allocation are in [preregistration.json](preregistration.json). The eight graph files are already included in the repository under `data/CP-SCALE-AU-L002/`. The exact source change for the 900-second C05 arms is in [source_patch_public.json](provenance/source_patch_public.json); the original signed receipt hash is retained there without copying machine-specific absolute paths into this release.

The independent [audit_aggregate_900s.py](scripts/audit_aggregate_900s.py) reopens the graph files, checks result identity and registered hashes, recomputes the integer objective, verifies the selected contacts are feasible, and calculates the equal-view mean and paired view/seed deltas. [build_public_result_package.py](scripts/build_public_result_package.py) exports an explicit allowlist of numeric fields and receipt hashes from the complete private audit. The public per-position CSV contains result hashes and numeric fields, without model request or response content.

The complete Codex model inputs and outputs are saved as compressed files in a private local archive for later analysis. The public release includes only their manifest hash and aggregate count/size, and must not include raw prompts, model outputs, credentials, relay logs, or connection details. The model response IDs and snapshot IDs in the private result records allow the independent audit to link them to the private archive.

The `main` branch carries the C05 LLM arm and shared protocol. KNN, LinUCB, and the original CHILS comparator implementation and runners belong on `non-llm-controls`. The original historical solver source was copied into an isolated experiment root for this run; repository packaging differences from the frozen candidate remain documented in `provenance/source_manifest.json` at the repository root.
